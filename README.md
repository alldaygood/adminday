# BIZ-G DAY V3 — นับวันตามไฟล์แนบ

## ติดตั้ง
แตก ZIP แล้วนำ index.html และ logo.png ไปแทนไฟล์เดิม หรือเปิด index.html บนเครื่องได้ทันที
CSS และ JavaScript รวมอยู่ใน index.html ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

## การนับวัน
เวอร์ชันนี้ใช้สูตรแพ็กเกจปกติตรงกับ adminday-main(1).zip ที่แนบมา:
- แพ็กเกจ 1 วัน: วันเริ่มต้น + 1 วัน
- แพ็กเกจตั้งแต่ 2 วันขึ้นไป: นับวันเริ่มต้นเป็นวันที่ 1 หรือวันเริ่มต้น + จำนวนวัน - 1
- หากติ๊กรับโปร: บวกวันฟรีเพิ่มจากวันที่สิ้นสุดปกติอีกครั้ง
- หากไม่ติ๊กโปร: ใช้จำนวนวันแพ็กเกจปกติ
- เอาติ๊กออกแล้วกลับเป็นวันที่สิ้นสุดปกติ ไม่มีการบวกสะสม

สูตร 1 วันเป็นกรณีพิเศษตามต้นฉบับ จึงต่างจากวิธีนับของแพ็กเกจอื่น
วันฟรีบวกหลังคำนวณแพ็กเกจปกติเสมอ เพื่อให้ติ๊กฟรี 1 วันแล้ววันที่เพิ่มอีก 1 วันจริง รวมถึงแพ็กเกจ 1 วัน

## สิ่งที่ปรับจาก V2
- ลบช่องเวลาเริ่มต้นทั้งหมด
- ลบการแสดงชั่วโมงและข้อความเกี่ยวกับการนับแบบ 24 ชั่วโมง
- ผลลัพธ์และข้อความคัดลอกแสดงเฉพาะวันที่กับจำนวนวัน
- ใช้สูตรนับวันจากไฟล์แนบแทนสูตรเดิมของ V2
- คง UI เทา ดำ แดง การ์ดโค้ง เอฟเฟกต์สั้น และการจัดวางสำหรับจอเล็ก
- คงช่องติ๊กรับโปร (ไม่ติ๊กเป็นค่าเริ่มต้น) และระบุจำนวนวันฟรีได้ ค่าเริ่มต้น 1 วัน
- คงชื่อ โลโก้ และลิงก์เดิม

## วิธีใช้
1. เลือกเริ่มวันนี้ หรือเลือกวันที่เอง (ปี ค.ศ.)
2. เลือกแพ็กเกจหรือกรอกจำนวนวันเอง
3. ติ๊กโปรเฉพาะเมื่อต้องการเพิ่มวันฟรี
4. คัดลอกวันที่สิ้นสุดหรือคัดลอกสรุปแพ็กเกจ

ระบบรองรับวันที่ข้ามเดือน ข้ามปี และปีอธิกสุรทิน
“วันนี้” อ้างอิงวันที่ประเทศไทย แต่ไม่มีช่องเวลาและไม่มีผลลัพธ์เป็นชั่วโมง
ปุ่มแพ็กเกจใช้จำนวนวันตายตัวตามที่แสดง ไม่ใช่การบวกเดือนปฏิทิน
ฟอนต์ออนไลน์อาจไม่โหลดเมื่อไม่มีอินเทอร์เน็ต แต่ฟอนต์สำรองและการคำนวณยังทำงาน

## ตรวจสอบ
เทียบสูตรกับฟังก์ชันจากไฟล์แนบโดยตรง ครบทุกปุ่มแพ็กเกจ ในวันเริ่มต้นตัวแทนช่วงข้ามเดือน ข้ามปี และกุมภาพันธ์
ตรวจวันฟรี 1 และ 4 วัน รวมการเปรียบเทียบ 288 กรณีผ่านทั้งหมด
ตรวจเปิด/ปิดโปรซ้ำ แพ็กเกจ 1 วัน ข้อมูลผิด ไวยากรณ์สคริปต์ และไฟล์อ้างอิงแล้ว
ยังไม่ได้ทดสอบภาพหน้าจอและการใช้งานจริงในเบราว์เซอร์ทุกอุปกรณ์
